# Accés a Dades - 2DAM

Esta carpeta contiene los ejercicios, prácticas y proyectos desarrollados en la asignatura **Accés a Dades** durante el curso 2º DAM.

El objetivo de esta asignatura es trabajar con diferentes métodos de **persistencia de datos**, comprender cómo se almacenan, procesan y transforman en distintos formatos, y aplicar estos conocimientos en aplicaciones reales.

## Contenido

- **UD3_Ejercicio_Obligatorio**  
  Proyecto completo de persistencia de datos en Python, con conversión entre formatos CSV, JSON, XML, HTML y PICKLE. Incluye validación, serialización, deserialización y una interfaz gráfica con Tkinter.

## Tecnologías utilizadas
- Python 3  
- Tkinter  
- BeautifulSoup4  
- csv, json, pickle  
- Git / GitHub  

---

## Objetivo del repositorio
Reunir de manera organizada todos los trabajos realizados en la asignatura Accés a Dades, facilitando su consulta y sirviendo como portfolio técnico.
